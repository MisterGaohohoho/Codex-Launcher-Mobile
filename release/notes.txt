Adds image and file attachments: system Photos, Camera, and Files selection; private per-session drafts; resumable uploads; pure attachment messages; image previews; bounded text/code reading; and attachment history across branches.

Conversations now open directly to messages. Execution records and file changes move to the session menu. Tap the title or use the menu to rename a session; new sessions can be named during creation. Pull down to load earlier messages or refresh, with the manual history button retained. The current model appears beneath the conversation title.

The Run control card also displays the PC's resolved model name, including CLI command/configuration models and the model recorded for a running request.

Drafts and pending sends survive process restart. Uploads pause in the background and resume manually. A changed active turn requires confirmation; uncertain model commands are checked without automatic replay. The original icon, pairing credentials, permissions, and signed update mechanism are retained.

Attachments and resolved Run models require Launcher desktop 2.8.0-beta.2 or later. Earlier desktops keep text conversations and existing controls; the attachment entry explains the required upgrade. Install the matching PC update when current tasks can safely stop; pairing does not change.

This release implements the attachment M1 stage. PDF/Office parsing and OCR are not included; unsupported formats remain downloadable files with an explicit read status. Image understanding depends on the selected model/provider. Automated native UI, transport, storage, and isolated Codex integration checks are covered. Physical camera, device-specific background behavior, and on-device upgrade checks remain to be completed on a target phone.
